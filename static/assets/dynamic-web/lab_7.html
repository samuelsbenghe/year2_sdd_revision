Introduction & Pedagogical Goals

In Week 6, we built a full-stack Python application using Flask, WSGI, and SQLite. That architecture required creating an isolated virtual environment, installing external packages via pip, defining explicit URL route decorators, and starting a long-running local process on a custom port.

In this lab, we explore a fundamentally different web architecture: PHP 8.3 running on a shared production web server (doc.gold.ac.uk). Powering approximately 75% of websites with a known server-side language, PHP uses a shared-nothing, file-based execution model:

  1. Zero-Process Deployment (~/public_html): You do not need to start, stop, or manage a web server process. The department server at doc.gold.ac.uk is already running and configured to serve files from your ~/public_html directory at https://doc.gold.ac.uk/~yourusername/.

  2. File-Based Routing: The web server maps URL paths directly to .php files inside your public_html directory (https://doc.gold.ac.uk/~yourusername/lab7/toolbox.php executes ~/public_html/lab7/toolbox.php). No route decorator table is required.

  3. Shared-Nothing Lifecycle: Each incoming HTTP request initializes a fresh environment, populates built-in superglobal arrays ($_GET, $_POST, $_SERVER, $_FILES, $_SESSION), executes the script from top to bottom, and releases all request memory immediately upon completion.

  4. Native HTML Interleaving: Rather than compiling a separate template language like Jinja2, PHP is an HTML-embedded language. Any text outside <?php ... ?> tags is streamed directly to the client browser as raw HTML, while Zend OPcache stores pre-compiled bytecode in shared memory for fast execution.

Step 1: The Single-File Dispatcher Pattern (toolbox.php)

When hosting multiple interactive tools on a single page, the script needs a mechanism to determine which form was submitted. We solve this using the Single-File Dispatcher Pattern:

  • Every tool card contains its own <form method="POST"> element.

  • Inside each form, a hidden input (<input type="hidden" name="tool" value="...">) identifies the specific micro-app.

  • At the top of toolbox.php, we inspect $_POST['tool'] using the null-coalescing operator (??) and run only the matching block of logic, storing results in an $out associative array.

Crucial Security Note: Manual Output Escaping

Unlike Flask’s Jinja2 engine—which automatically escapes variables placed inside {{ ... }}—raw PHP outputs strings verbatim. If you echo unescaped user input directly into the page, an attacker can submit <script>...</script> and trigger a Cross-Site Scripting (XSS) vulnerability. Always wrap dynamic values in htmlspecialchars($value, ENT_QUOTES, 'UTF-8') before rendering them inside HTML.

if ($tool === 'hash') {
    $in  = $_POST['text'] ?? '';
    $rng = new \Random\Randomizer();

    $out['bcrypt'] = password_hash($in, PASSWORD_DEFAULT);

    $out['token']  = $rng->getBytesFromString('ABCDEFGHJKLMNPQRSTUVWXYZ23456789', 12);

Tool 3: Base64 & URL Codec

Web applications frequently encode binary data or JSON payloads into URL-safe strings (such as the first segment of a Flask session cookie). Note the use of PHP 8’s named argument strict: true in base64_decode(), which rejects strings containing characters outside the Base64 alphabet, and mb_check_encoding(), which verifies that the decoded bytes form valid printable UTF-8 text before displaying them.

// --- TOOL 3: BASE64 & URL CODEC (Paste in top PHP block) ---
if ($tool === 'codec') {
    $s = $_POST['str'] ?? '';
    $out['b64_enc'] = base64_encode($s);
    $decoded = base64_decode($s, strict: true);
    $out['b64_dec'] = ($decoded !== false && mb_check_encoding($decoded, 'UTF-8'))
        ? $decoded
        : '(Input is not valid UTF-8 Base64)';
    $out['url_enc'] = rawurlencode($s);
}

Tool 4: Natural-Language Date & Unix Epoch Converter

PHP’s strtotime() function includes a C-level parser for English relative date expressions (such as "next Monday", "+3 weeks", or "last Friday 17:00"), converting them into Unix timestamps (seconds elapsed since 1 January 1970 00:00:00 UTC).

// --- TOOL 4: NATURAL-LANGUAGE DATE & UNIX EPOCH CONVERTER (Paste in top PHP block) ---
if ($tool === 'date') {
    $expr = trim($_POST['expr'] ?? 'now');
    // If input is purely numeric, treat it as a Unix epoch timestamp; otherwise parse English text
    $ts = is_numeric($expr) ? (int) $expr : strtotime($expr);
    if ($ts !== false) {
        $out['unix']  = (string) $ts;
        $out['human'] = date('l, jS F Y H:i:s T', $ts);
        $out['iso']   = date('c', $ts);
    } else {
        $out['error'] = 'Could not parse date expression.';
    }
}

Tool 5: Safe DNS & IP Inspector (SSRF Defense in PHP)

In Week 6, we used Python’s ipaddress module to prevent Server-Side Request Forgery (SSRF) against loopback (127.0.0.1), private networks (10.x.x.x, 192.168.x.x), and cloud metadata endpoints (169.254.169.254). In PHP, filter_var() provides built-in bitmask flags (FILTER_FLAG_NO_PRIV_RANGE | FILTER_FLAG_NO_RES_RANGE) to enforce the exact same boundary check in a single expression.

// --- TOOL 5: SAFE DNS & IP INSPECTOR (Paste in top PHP block) ---
if ($tool === 'net') {
    // Sanitize hostname to allow only valid DNS characters
    $host = preg_replace('/[^a-zA-Z0-9.-]/', '', $_POST['host'] ?? '');
    $ip   = gethostbyname($host);

    // Validate that the resolved IPv4 address is strictly public
    $safe = filter_var(
        $ip,
        FILTER_VALIDATE_IP,
        FILTER_FLAG_NO_PRIV_RANGE | FILTER_FLAG_NO_RES_RANGE
    );

    if ($safe !== false) {
        $rdns = gethostbyaddr($safe);
        $out['res'] = "Host: $host\nIPv4: $safe\nrDNS: $rdns";
    } else {
        $out['res'] = "Blocked: Private, loopback, reserved, or unresolvable address ($ip).";
    }
}

  <div class="card">

Tool 6: Multibyte Text Analyzer & URL Slugifier

Standard C-style string functions like strlen() count bytes rather than characters, meaning a multi-byte UTF-8 character (such as £ or é) is counted as 2 bytes. PHP’s mb_strlen() (Multibyte String length) accurately counts UTF-8 code points. Meanwhile, preg_replace() uses Perl-Compatible Regular Expressions (PCRE) to convert arbitrary titles into clean, hyphenated URL slugs.

// --- TOOL 6: MULTIBYTE TEXT ANALYZER & SLUGIFIER (Paste in top PHP block) ---
if ($tool === 'text') {
    $txt = $_POST['body'] ?? '';
    $out['words'] = str_word_count($txt);
    $out['bytes'] = strlen($txt);
    $out['chars'] = mb_strlen($txt, 'UTF-8');
    $out['slug']  = trim(preg_replace('/[^a-z0-9]+/', '-', strtolower($txt)), '-');
}

Task A: Session-Backed Activity Log ($_SESSION)

Because PHP uses a shared-nothing architecture, variables like $out are destroyed at the end of every HTTP request. To remember which tools a user has run across multiple form submissions, we use PHP’s built-in session manager.

How It Works & Implementation Tips:

  1. Call session_start(); at the very top of toolbox.php (right after declare(strict_types=1); and before any HTML is sent). PHP will automatically generate a PHPSESSID cookie and store session state on the server.

  2. Initialize an array in $_SESSION['history'] if it does not yet exist.

  3. Whenever $tool !== '', append a timestamped entry to $_SESSION['history'] and keep only the latest 5 entries using array_slice().

// 1. Place right after declare(strict_types=1);
session_start();
if (!isset($_SESSION['history'])) {
    $_SESSION['history'] = [];
}

// 2. Place right after $tool = $_POST['tool'] ?? '';
if ($tool !== '') {
    array_unshift($_SESSION['history'], strtoupper($tool) . ' executed at ' . date('H:i:s'));
    $_SESSION['history'] = array_slice($_SESSION['history'], 0, 5);
}

To display the history bar, add a <div class="card" style="margin-bottom: 20px;"> above <div class="grid"> and loop over $_SESSION['history'] using foreach ($_SESSION['history'] as $item). Challenge: Add a small form with value="clear_history" that calls $_SESSION['history'] = [];.

Task B: Fuzzy Keyword Spellchecker (levenshtein())

The Levenshtein distance between two strings is the minimum number of single-character edits (insertions, deletions, or substitutions) required to transform one word into another. Unlike Python or JavaScript (which require third-party packages or manual dynamic programming matrices), PHP includes levenshtein() in its standard C library.

How It Works & Implementation Tips:

  1. Create a 7th card with <input type="hidden" name="tool" value="spell"> and a text input named term.

  2. In your top PHP block, iterate over a dictionary of computing terms, compute levenshtein(strtolower($term), $word) for each entry, and track the word with the lowest edit distance:

if ($tool === 'spell') {
    $term = strtolower(trim($_POST['term'] ?? ''));
    $dictionary = [
        'authentication', 'authorization', 'bytecode', 'cookie', 'cryptography',
        'database', 'decorator', 'equirectangular', 'framework', 'gateway',
        'idempotent', 'middleware', 'opcache', 'parameterized', 'sqlite', 'webhook'
    ];

    $shortest = -1;
    $closest  = '';

    foreach ($dictionary as $word) {
        $dist = levenshtein($term, $word);
        if ($dist === 0) {
            $closest  = $word;
            $shortest = 0;
            break; // Exact match found
        }
        if ($shortest < 0 || $dist < $shortest) {
            $closest  = $word;
            $shortest = $dist;
        }
    }

    $out['spell_result'] = ($shortest === 0)
        ? "Exact match: '$closest'"
        : "Did you mean '$closest'? (Edit distance: $shortest)";
}

Task C: Multipart File SHA-256 Checksummer ($_FILES & hash_file())

When a user uploads a file via an HTML form with enctype="multipart/form-data", PHP intercepts the incoming stream, writes the file to a temporary directory on the server, and populates the $_FILES superglobal array before your script starts.

How It Works & Implementation Tips:

  1. In your HTML card, the <form> tag must include method="POST" enctype="multipart/form-data". Without enctype, the browser only sends the filename string rather than the file contents.

  2. Check that $_FILES['upload']['error'] === UPLOAD_ERR_OK before reading $_FILES['upload']['tmp_name'].

  3. Use hash_file('sha256', $tmpPath) rather than file_get_contents() so PHP streams the file in small chunks without exhausting RAM.

if ($tool === 'filehash' && isset($_FILES['upload'])) {
    if ($_FILES['upload']['error'] === UPLOAD_ERR_OK) {
        $tmp  = $_FILES['upload']['tmp_name'];
        $name = basename($_FILES['upload']['name']);
        $size = $_FILES['upload']['size'];
        $sha  = hash_file('sha256', $tmp);
        $out['file_info'] = "File: $name ($size bytes)\nSHA-256: $sha";
    } else {
        $out['file_info'] = "Upload error code: " . $_FILES['upload']['error'];
    }
}

Task D: PHP Syntax Highlighter (highlight_string())

PHP exposes its internal Zend lexical scanner via highlight_string(). When passed a string containing <?php ... ?> code and return: true, it returns HTML <span> elements colored according to token type (keywords, strings, variables, comments).

How It Works & Implementation Tips:

  1. Note that because highlight_string() intentionally returns safe HTML <span> tags, this is the one place where you render the result directly without wrapping the output in htmlspecialchars().

  2. If the user’s input does not start with <?php, prepend "<?php\n" before passing it to highlight_string() so the lexer activates tokenization mode:

if ($tool === 'highlight') {
    $code = $_POST['code'] ?? '';
    if (!str_starts_with(trim($code), '<?php')) {
        $code = "<?php\n" . $code;
    }
    // Returns colorized HTML <code><span>...</span></code>
    $out['highlighted_html'] = highlight_string($code, return: true);
}

In your card template, wrap $out['highlighted_html'] inside a light-background container (<div style="background:#f8fafc; padding:12px; border-radius:6px; overflow-x:auto;"><?= $out['highlighted_html'] ?></div>) so the default syntax colors have high contrast.
